# Adversarial review: 6.4b, the app runs the install (26 Nov 2026)

Scope: `git diff 19cc1aa..HEAD` on `feat/6.4b-app-runs-install` (head `023e9c7`). Read-only review.
Checked against golden rules 1 to 10, threat model T-02, T-15, T-17 and questions 16, 34, 35, 39, 42, the
`helper-protocol` caller rules, and `pkexec(1)` from polkit 128.

"Probe" = a temporary test on the public API of `tidewise-app` (`cargo test --offline -p tidewise-app`), removed
afterwards. "Read" = from reading the code only.

## Checked, nothing found

- **"Nothing was changed" strings.** Every `ErrorKind` text that says it comes, for a plain install (the only action
  the app sends), from before the real run: gate refusals, dry run, `-Qu`, provider check. `PacmanFailed` and
  `DatabaseLocked` do not claim it. The app's own uses (126, 127, helper missing, exit 2, spawn failed, not sent,
  prompt closed) match `pkexec(1)` and the helper's exit codes (0, 1, 2).
- **Request against the review.** Targets, providers and transaction are taken from the reviewed `InstallPlan`; the
  summary is made after `validate`, by the shared function. Item order is pacman's.
- **Deadlocks.** stdin has its own thread, stderr its own, stdout is read to its end on the job thread; none is on the
  window's thread. A line is never held beyond the cap plus one byte.
- **State races.** While `Installing`: `open`, `open_group`, `try_again`, `cancel`, `back` change nothing; late or
  foreign job and resolve answers are dropped.
- **Resolver against helper.** For the answers kept by `named_once` the dry-run names and the provider rules match.
- **Keyboard.** No trap seen; the progress card has nothing focusable, the end cards focus their first button.
- **Golden rules 1, 3.** Absolute paths, argument list, cleared environment plus `LC_ALL=C`, no shell.

## Not checked

- `pkexec`, the app and the helper were **not run**; no real password window, agent, signal or terminal behaviour

- The new container resolver test and dummy PKGBUILDs were not reviewed beyond the diff's file list.
- Nothing was looked at on screen: layout, contrast, screen reader output, focus order in a real window.

- Questions 42 b to d were not re-examined.
