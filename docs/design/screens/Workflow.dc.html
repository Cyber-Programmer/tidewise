Rules every flow follows
1. Show exactly what will change before changing it.
2. Ask for the password once per action, through the system prompt.
3. Your own files go to Trash; nothing personal is deleted outright.
4. Every change is written to History, with Undo where it's possible.
5. Protected system parts never get a remove, stop or end button.
