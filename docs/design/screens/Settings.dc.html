Admin access

Set up

Some fixes need admin rights, like clearing package downloads or stopping a service. Tidewise asks through your system's own password prompt. It never sees, stores or sends your password.

A small helper does only a fixed list of actions (clean package cache, trim logs, remove packages, manage services). It can't run anything else.

helper: /usr/local/libexec/tidewise-helper (root:root 0755, sha256 verified)
policy: /usr/share/polkit-1/actions/io.github.tidewise.helper.policy
actions: clean-pkg-cache · vacuum-journal · remove-package · service-control

About

Tidewise is free, open-source software (GPL-3.0). It works on any distro that uses pacman, apt, dnf or zypper, plus Flatpak, Snap and AppImage apps.
